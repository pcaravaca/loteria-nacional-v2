App para Android

Instalá la app nativa para apostar sin navegador. Usa el mismo usuario y saldo.

Descargar APK
·
  1. Descargá el archivo LoteriaNacional.apk.
  2. Abrilo con el botón «Instalar».
  3. Si te lo pide, habilitá «Instalar apps desconocidas» para este navegador o gestor de archivos.
  4. Entrá con tu correo y clave de siempre.

La app se actualiza sola: avisa cuando hay una versión nueva.
